Read the CPRS (connected-system permission reconciliation) service settings.

**Status:** validated on the lab. **Evidence:** server code + live 2026-10-30.

**Answer:** {enableCprs: bool, cleanupTimeInDays: int, pollingInterval: int}

**Example:** GET …/access/administration/cprsConfig -> {enableCprs:true, cleanupTimeInDays:7, pollingInterval:10}
